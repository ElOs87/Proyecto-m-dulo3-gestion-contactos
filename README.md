# Proyecto-m-dulo3-gestion-contactos
El proyecto consiste en un Sistema de Gestión de Contactos desarrollado en Python, que permite agregar, buscar, editar, eliminar y listar contactos mediante un menú interactivo en consola. Cada contacto almacena nombre, teléfono, correo y dirección, utilizando estructuras de datos y programación orientada a objetos vistas en el módulo.
